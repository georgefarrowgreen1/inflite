# InFlite 4.30

The permanent six-slot dock keeps its existing account-owned app instances and icon transitions. Edit now includes an explicit favourite-order strip: drag a favourite onto another position or focus it and use the arrow keys. Pinning and unpinning still operate in the labelled app grid. Only the same bounded list of validated app IDs is saved under the account's device preference key.

A press-and-hold, right-click or keyboard context-menu command opens app actions. Open resumes the app; Calendar, Notes, People, Mail and Chats also offer their supported creation action. Actions recheck the owner, route and app access, then use the existing native provider. Cold shortcuts open the canonical app route before running. Inside the library the actions are an inner sheet page, with Back/Escape returning to the library; dock shortcuts use the shared sheet. Movement, cancellation, resize, hidden documents and account teardown release pointer work. Closing the library releases its input listeners.

Notes and People hide redundant library headings and avoid showing controls briefly before an empty library resolves. Notes retain a quiet writing surface and list/grid collections; People retain alphabetical groups and contact profiles. Calendar keeps week/month navigation and a distinct schedule column on wide screens. Cards, fields and searches use rounded neutral surfaces, consistent insets and readable content layers; app identity stays in icons and small marks. The old layered stylesheet overrides are consolidated. An empty-state null text node is removed, and unchanged calendar date controls retain their DOM during save/status updates.

Native editor Back returns to its collection, restoring its remembered scroll and originating record focus. Unsaved contacts/events can explicitly keep an encrypted device draft and close; this does not publish an incomplete cloud record. Autosave, conflict review, linked items and the singleton app lifecycle are preserved. The shared sheet's Back/Escape pops an inner page before dismissing the window. Existing standalone edge Back, native browser history, swipe-to-dismiss and reduced-motion behavior remain available.

Quiet launcher marks use only ready provider facts: attention, saving, an open draft, pending sync, or a positive unread count. Mail supplies the unread counts from its two inbox lenses; unlocked Chats supplies its actual unread total. Unknown, locked and signed-out snapshots show none. Files uses its account-owned transfer service for active uploads and known progress, clearing the mark on completion. These facts stay in memory; no additional startup fetch, polling, notification permission, app content cache or persisted count is introduced.

Validation includes real creation through the launcher, pin ordering by pointer and keyboard, nested Back/Escape, upload updates, malformed/locked badge inputs, draft retention and account isolation, both browser engines, light/dark/narrow/wide app views, security/API contracts, offline asset closure and the existing fixed byte budgets. The native app graph is published under immutable 4.30 paths; previous release graphs remain untouched.
