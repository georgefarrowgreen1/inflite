# InFlite 4.11.1 ecosystem audit

This review covers the shell and its updates, signed-in apps, account and sign-in, public Status, Mail delivery, the app-service boundary, scheduled connector jobs, and the public website. Browser and API exercises used local accounts, synthetic records and controlled upstream responses.

| Area | What changed and how it was checked |
| --- | --- |
| Updates | A hidden busy indicator could defer a new release indefinitely. The shell now checks visible work, retries interrupted checks and saves its reload guard when a reload is actually going ahead. The service worker distinguishes an embedded app frame from a second independent tab. Browser fixtures cover deferred updates, failed installs, asset integrity and multiple clients. |
| Shell and Settings | Settings cancel abandoned reads, report uncertain writes, and restore the saved value. Search highlights the correct occurrence. Sign-out preserves work when the service cannot confirm the request. Sign-in return paths must resolve to the local origin. Chromium and WebKit exercised these behaviours. |
| Files and organisers | Reviews covered owner isolation, expired preview URLs, interrupted file actions, offline edits, focus, navigation and lifecycle. Notes now reconciles an in-flight save with later edits in the same tab. Calendar, People and Notes share the versioned 4.31.2 organiser runtime. |
| Mail | Mail serialises overlapping saves, preserves attachment and quote metadata on recovery, and protects queued messages across tabs and account changes. Locked Mail clears its header metadata. Startup stays below the existing 87,000-byte gzip budget. Tests exercised mail parsing, recurrence, delivery retries, offline data, compose and mailbox geometry. |
| Weather, Fitness and Markets | Hosted apps verify ownership before applying private results. Weather filters search and preference writes by owner, discards previous-account places and recovers from corrupt local data. Local browser flows covered mobile and desktop, and a database fixture confirmed stale saves do not alter the current account. |
| Account and Chats | Sign-out needs a confirmed response. Chats removes the signed-out session’s push subscription while preserving another device’s registration. Cross-device drafts and open Account panels are bound to the current owner. Browser and database fixtures exercised session transitions. |
| APIs, connectors and Status | Private aggregate health checks strip visitor identity and network metadata. Upstream calls apply byte and time limits and distinguish invalid versions, redirects and provider failures. The scheduler accepts three-part release versions. Notification clicks respect their target tab. Schema setup is scoped to a database binding and retries transient failures. Status was exercised across eight widths, light and dark themes and healthy and incident states. |
| Public pages and enquiries | The public website describes ten apps and links to privacy, terms and device-storage information. The contact form uses the existing administrator inbox. Browser and database fixtures cover required fields, duplicate clicks, failed or throttled delivery, successful storage, and safe error responses. Messages contain the fields entered by the visitor. Keyed network identifiers limit abuse separately. |
| Supply chain and delivery | Reviewed both repositories’ workflows and tracked files for credential exposure. Checked four locked dependency trees against advisory data and checked package integrity. The shell build now compresses its framework modules before delivery and fingerprints the exact bytes it serves. The measured core is 39,649 bytes gzipped against its 39,936-byte limit. Paired production assets and all 32 Weather offline fingerprints were regenerated and verified. |

## Scope of verification

The audit combines source inspection, browser interactions, service workers, local database and storage fixtures, simulated upstream failures and dependency advisory checks. The preference to lock page zoom was retained. Browser emulation includes Chromium and WebKit. It does not reproduce every behaviour of an installed app on physical iOS hardware. Live mail delivery, live Garmin or Strava accounts, push delivery to physical devices, hardware passkeys, production backup retention and recovery procedures need operational evidence. A passing advisory scan describes the dependencies and advisories known at the time of the check.

The public notice records the product behaviour inspected here. Controller identity beyond the supplied trading name, legal bases, sensitive fitness processing, overseas transfer arrangements and retention decisions still require the operator’s review. The accompanying privacy decision record identifies the outstanding evidence.
