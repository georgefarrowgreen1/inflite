# InFlite 4.03

Liquid Glass now responds consistently across Today, Calendar, Notes, People, Files, the shell, Mail, Fitness, Weather, Markets, Chats and Account. Fine mouse pointers create a bounded local highlight on neutral controls and chrome; individual controls gain a subtle lift. Touch controls respond with a short, restrained press. Native clicks, focus, text selection, keyboard entry and scrolling remain intact. There is no idle animation loop or pointer capture.

Account → Appearance includes a Liquid Glass switch, a native 0–100 intensity slider and a live preview. The default is 70. Intensity controls translucency, edge light, depth and chrome blur/saturation while retaining the tested contrast floor. Zero gives a flat opaque material; off also disables the extra material feedback and remembers the selected level. Dragging previews locally, committing coalesces preference saves, cancel restores the committed setting, and failed saves restore the last acknowledged account preference. Owner replacement and late responses are fenced. Pending committed choices flush when Account hides or leaves; Appearance requests use keepalive without changing the single-flight ordering. An unfinished drag is canceled on departure.

Preferences are validated booleans/integers at the existing same-origin authenticated account boundary. Nullable database migrations provide defaults without changing old accounts; older clients preserve omitted fields. The small private no-store preference response and standalone app projections include the new settings. Only appearance preferences are cached locally; no private app data is added to the cache. Incoming cross-tab preferences are applied without writing them back, preventing stale storage echoes from replacing a newer local slider choice.

Pointer updates affect one eligible surface and schedule at most one animation frame. Scrolling, hidden pages, pointer exit, off/zero intensity, owner changes and accessibility preference changes clear them. Semantic primary/destructive/selected controls and chart/map/media surfaces retain their own fills. Reduced motion, reduced transparency, higher contrast and forced colors continue to take priority. No window, input field, toolbar or repeated content container is transformed.

The 4.02 immutable native app release graph remains unchanged. This release updates shared runtime/materials and account controls. Validation covers Chromium and WebKit controls, actual Account saves and rollback, keyboard/mobile geometry, contrast at 0/70/100 in all six palettes and both display modes, backend validation/persistence/isolation, existing app contracts and size budgets.
