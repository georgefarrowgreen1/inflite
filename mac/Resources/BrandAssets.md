# Site logo sources

These are unchanged copies of the site's SVG artwork. The native asset compiler preserves vector representations
and original colours. Refresh these copies when the corresponding site logos change; do not redraw them in SwiftUI.

| Asset | Site source |
|---|---|
| LogoInFlite | `today/public/icon.svg` (`https://inflite.ai/icon.svg`) |
| LogoMail | `today/public/apps/mail.svg` |
| LogoWeather | `today/public/apps/weather.svg` |
| LogoFitness | `today/public/apps/fitness.svg` |
| LogoMarkets | `today/public/apps/markets.svg` |
| LogoChats | `today/public/apps/chat.svg` |
| LogoAccount | georgefarrowgreen repository, `account/icon.svg` (`https://account.inflite.ai/icon.svg`) |

`AppIcon.png` is the site's existing `today/public/icon-512.png`, used to generate the Dock icon.
The website itself continues to load its own assets normally; these bundled assets cover native window and menu branding.
